Para quem é este guia

Feito para quem vai acompanhar a própria obra —
não para quem vai executá-la sozinho.

Este guia é para você se
  • Vai construir sem contratar uma construtora e quer entender o que está pagando.
  • Vai contratar pedreiro, eletricista e encanador separadamente e precisa saber o que cobrar de cada um.
  • Quer reconhecer erros antes que virem parede fechada.
  • Já tem ou está buscando um arquiteto/engenheiro responsável e quer participar das decisões com mais repertório.
Este guia não é para você se
  • Procura um curso de pedreiro, eletricista ou encanador para executar a obra sozinho.
  • Busca um substituto para o projeto e a ART/RRT de um profissional habilitado.
  • Quer cálculo estrutural pronto — dimensionamento é sempre responsabilidade do engenheiro.
